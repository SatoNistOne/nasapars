# SpaceVault

Автор: Гаврилов Н.С.

Десктопное приложение-каталог для работы с медиабиблиотекой NASA: снимки космоса, научные видео, «Фото дня» (APOD) и данные о сближающихся с Землёй астероидах.

## Суть проекта

Собрать в одном удобном интерфейсе разрозненные источники NASA (Images Library, APOD, NeoWs) с возможностью поиска, коллекционирования, локального хранения и экспорта в PDF.

## Целевая аудитория

Студенты технических и естественнонаучных специальностей, преподаватели астрономии, любители космоса, научные журналисты.

Главная задача пользователя: быстро найти снимок или видео по запросу (миссия, объект, дата), отобрать лучшие кадры в тематическую коллекцию и получить готовый PDF-каталог для презентации или учебного материала.

## Возможности

- Галерея фото и видео с миниатюрами, пагинацией и фильтрами
- Полнотекстовый поиск по названию, описанию и тегам
- Сортировка по дате, названию, рейтингу, размеру файла, миссии
- Карточка снимка с редактированием тегов, рейтинга, заметок
- Автоматический перевод описаний на русский
- Импорт из NASA Image and Video Library с прогресс-баром
- Синхронизация «Фото дня» (APOD)
- Данные об астероидах (NeoWs) с таблицей и графиками
- Коллекции с экспортом в PDF
- Управление тегами
- Тёмная тема
- Автозагрузка демо-данных при первом запуске

## Стек

- Python 3.11–3.14
- PySide6 (Qt6) — кроссплатформенный GUI (Windows, Linux)
- SQLite — портативная база данных (файл spacevault.db)
- SQLAlchemy 2.0 — ORM
- NASA Images API — поиск снимков и видео
- NASA APOD API — «Фото дня»
- NASA NeoWs API — данные об астероидах
- MyMemory Translate API — перевод описаний
- QThreadPool + QRunnable — асинхронные загрузки без блокировки UI
- PyInstaller — сборка исполняемого файла

## Компоненты приложения

### Галерея
Сетка миниатюр с пагинацией по 60 элементов, поиск с debounce 300 мс, фильтры (миссия, тип, теги, диапазон дат, избранное), сортировка, контекстное меню, кнопка сброса фильтров.

### Карточка снимка
Полноразмерное изображение, цветные бейджи (тип, миссия, избранное), метаданные, описание с кнопкой перевода, теги-чипсы, звёздный рейтинг, многострочные заметки, добавление в коллекцию, экспорт файла, переход на страницу NASA.

### Коллекции
Создание, переименование, удаление коллекций. Добавление и удаление снимков. Счётчик снимков в каждой коллекции. Экспорт в PDF с изображениями и описаниями.

### Астероиды
Таблица сближений с NASA NeoWs с сортировкой по клику на заголовок. Фильтр по потенциально опасным объектам с подсветкой. Графики: столбчатый (сближения по дням) и диаграмма рассеяния (диаметр против расстояния).

### Теги
Управление тегами: переименование и удаление. Теги создаются автоматически при импорте из ключевых слов NASA.

### Импорт
Диалог загрузки по запросу из NASA с выбором типа медиа и количества. Прогресс-бар и отчёт о добавленных и пропущенных элементах.

## Схема данных

Таблицы SQLite:

- images — снимки и видео (nasa_id, title, description, date_created, credit, mission_id, file_path, file_size, thumbnail, video_url, rating, is_favorite, notes)
- missions — миссии (Hubble, JWST, Apollo, Mars, ISS)
- tags — теги
- image_tags — связь многие-ко-многим между снимками и тегами
- collections — пользовательские коллекции
- collection_images — связь многие-ко-многим между коллекциями и снимками
- asteroids — данные о сближениях астероидов (neo_id, name, diameter_max_m, is_hazardous, approach_date, velocity_kms, miss_distance_km)

Связи: один-ко-многим (mission к images), многие-ко-многим (images к tags, images к collections).
